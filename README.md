# Portfolio – Hari RANDRIA

Ouvrir `index.html` dans le navigateur.

## Où modifier quoi
- **Textes de chaque section** : `js/sections/` (un fichier par section : stats, apropos, atouts, competences, missions, services, parcours, contact). Modifiez le HTML entre les accents graves.
- **Ordre / retrait des sections** : `js/render.js` (liste ORDER).
- **Accueil, menu, pied de page** : `index.html`.
- **Titres qui s'écrivent à l'accueil** : `js/typing.js` (liste WORDS).
- **Couleurs et thème clair/sombre** : `css/base.css` (variables au début du fichier).
- **Style de chaque section** : `css/<section>.css` (hero, about, cards, competences, missions, parcours, contact, header, stats).
- **Mobile / tablette** : `css/responsive.css`.
- **Curseur** : `css/cursor.css` et `js/cursor.js`.
- **Photo** : remplacer `photo.jpg`. **CV** : remplacer `cv-hari-randria.pdf`.
